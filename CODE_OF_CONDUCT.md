# Правила общения

*English: be civil, keep discussions technical. Report abuse privately through
GitHub (Security tab → Report a vulnerability) if a public issue is not
appropriate.*

Проект небольшой, и правила такие же короткие.

## Чего ждём

- Обсуждаем код и задачи, а не людей. Замечание к правке — о правке.
- Спрашивать не стыдно. Вопрос новичка — обычный вопрос, а не повод для иронии.
- Несогласие нормально. Аргумент — тоже, переход на личности — нет.
- Языки общения — русский и английский, оба равноправны.

## Чего не допускаем

- Оскорблений, травли, придирок к человеку вместо разбора его работы.
- Выпадов по признаку происхождения, пола, возраста, вероисповедания,
  состояния здоровья, места работы или уровня опыта.
- Публикации чужих личных данных без разрешения.
- Рекламы и посторонних рассылок в issues и обсуждениях.

## Если правила нарушены

Напишите сопровождающему — в issue, если тема допускает публичность, или
личным сообщением через GitHub, если нет. Разберусь и отвечу.

Меры по нарастающей: просьба поправить формулировку, удаление сообщения,
закрытие темы, запрет на участие в репозитории. Мера выбирается по тяжести и
повторяемости, решение сообщается тому, кого оно касается.

Правила действуют в issues, обсуждениях, запросах на слияние и в описаниях
коммитов — везде, где идёт работа над проектом.
